# Web Design Prompt Builder

Webデザインの専門知識がなくても、少ない選択から生成AIへ渡せるデザインモックアップ画像用プロンプトを作成できるシングルページアプリです。

## 特徴

- サイト種別・業種・目的・想定ユーザー・印象・余白の好みからデザイン指示を生成
- 画像の表示範囲を絞り、長いページで起きやすい文字・余白の縮小を抑制
- 同じチャットで順番に使える、ページ上部・中部・下部の3分割プロンプトを一括生成
- 業種と印象、印象同士の組み合わせを内部ルールで調整
- 避けたい表現を明示し、好みと異なるデザインへの偏りを抑制
- 生成後の編集とクリップボードへのコピーに対応
- モックアップ画像用を中心に、デザイン構成・HTML/CSSプロトタイプ用のプロンプトにも対応
- 入力・生成処理はすべてブラウザ内で完結
- PCとスマートフォンに対応

## ローカルで確認する

外部依存はありません。リポジトリのルートで静的ファイルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## GitHub Pages

静的ファイルだけで構成されているため、GitHub Pages の公開元を `main` ブランチの `/ (root)` に設定すれば、そのまま公開できます。

## 構成

```text
/
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/app.js
└── README.md
```
